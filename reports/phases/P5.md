### 11.1 Root cause (independently root-caused by P6, fix owned by P5)

`packages/opencode/src/tool/websearch.ts` resolved `InstanceState.context` **inside the eager `Tool.define` init effect**:

```ts
export const WebSearchTool = Tool.define("websearch", Effect.gen(function* () {
  const config = yield* Config.Service
  const runtime = yield* WebSearchRuntime.Service
  const instance = yield* InstanceState.context   // ← line 109, EAGER init
  return { ... execute: (params, ctx) => Effect.gen(function* () { ... workspace: instance.directory ... }) }
}))
```

`Tool.define`'s init runs at **layer construction time**, and `ToolRegistry.layer` executes `const websearch = yield* WebSearchTool` (`src/tool/registry.ts:133`) while `AppLayer` is being built — i.e. on the first `AppRuntime.runPromise`, before any session, message or `InstanceRef` exists. `InstanceState.context` (`src/effect/instance-state.ts:14-18`) is documented per-directory state that dies when `InstanceRef` is absent, so every construction of the whole `AppLayer` (which contains `ToolRegistry.node`) died:

- `AppRuntime.runPromise(Effect.void)` → `APPRUNTIME_DIES: InstanceRef not provided` (P6 probe, `reports/phases/P6.md:453`);
- `InstanceRuntime.disposeAllInstances()` (`src/project/instance-runtime.ts:12`) is exactly `AppRuntime.runPromise(...)`, and `test/config/config.test.ts` calls it through `clear(true)` in **both** `beforeEach` and `afterEach` (`config.test.ts:125-150`) → every one of the 112 tests died;
- `test/tool/registry.test.ts` died at the same construction site.

This was a **layer-construction/type bug**, not a permission issue: `instance` was only ever used at one point — `workspace: instance.directory` in the `runtime.search(...)` scope, reachable only *after* every fail-closed gate. The package `AGENTS.md` forbids ad hoc ambient instance-context shims and says `InstanceState` is for per-directory state while `makeRuntime` is for services, so the correct fix is to resolve it at the point of use, exactly like `websearch-inspect.ts:28`, `grep.ts:51`, `read.ts:243` and `edit.ts:79` already do.

**No P7 debug marker remains.** A repo-wide search for `P7_INSTANCEREF_DEBUG` matches only the narrative in `reports/phases/P6.md`; `src/effect/instance-state.ts` contains no probe, trace or `console.*` and is byte-identical to its non-debug form. Nothing to remove.
