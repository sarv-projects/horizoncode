## Scope and evidence method

Read all 28 architecture Markdown files now present in `ARCH/` (numbered `00`–`28`, with `17` intentionally unused), the delivery ledger and run handoff, the repository research notes, and the relevant Rust paths. Rechecked current primary sources for Cline, Codex, OpenCode, ACP, DeepSeek-Reasonix, and MiMo-Code. Where source is unavailable, the boundary remains unknown.
