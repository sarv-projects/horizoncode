# Flow registry

| ID | Flow | Owner and contract |
|---|---|---|
| FLOW-TURN-001 | Direct coding turn | Session admission → pinned context → provider step → admitted tool batch → governed effects → ordered results → user outcome; no fabricated managed Run |
| FLOW-GOAL-001 | Prepare goal | Inert exact request → bounded read-only preparation → spec/graph/plan proposal → durable review challenge |
| FLOW-RUN-001 | Activate Run | Authenticated exact review → one-use approval receipt → reservation and durable activation → supervisor admission → dispatch outbox |
| FLOW-DISPATCH-001 | Dispatch worker | Ready graph node → budget/resource claims → workspace fence → stable launch intent → host receipt → owner lifecycle observation |
| FLOW-EFFECT-001 | Execute effect | Decode/preflight → authority/hook validation → durable prepare → confined dispatch → immediate settlement or UNKNOWN → ordered model projection |
| FLOW-RECOVERY-001 | Reconcile lost execution | Validate canonical heads → host/peer observations → effect/workspace/usage reconciliation → exact outcome; no guessed relaunch |
| FLOW-CANCEL-001 | Cancel target | Priority admitted intent → target-scoped fence → host cancellation → reconcile started work → durable terminal receipt |
| FLOW-COMPLETE-001 | Complete Run | Integrate exact revisions → independent required verification → validate freshness → settle required effects → completion; optional maintenance is separate |
| FLOW-ARTIFACT-001 | Inspect result | Scoped artifact query → bounded immutable version → preview/attach/open/export → exact-version feedback |
| FLOW-MEMORY-001 | Save/correct memory | Validated user save or advisory capture → owner transaction → passive receipt → scoped use → edit/forget generation fence |
| FLOW-INSTALL-001 | Install/onboard | Detect target → verified release metadata/bytes → user-scoped atomic activation → optional PATH setup → skippable route/workspace onboarding |
| FLOW-INDEX-001 | Update/query repository intelligence | Governed source view → change hint/digest validation → incremental base/overlay update → atomic generation publication → scoped bounded query → freshness/policy validation → context projection |
| FLOW-CHANGE-001 | Inspect coherent edits | Settle edit effects → observe revision → index delta → allowed formatter/diagnostics/checks → final diff/impact → ChangeReceipt → independent required verification |

Detailed normal, failure and recovery sequences live with the subsystem owner. This registry supplies identities and cross-owner boundaries rather than a second implementation of each flow.
